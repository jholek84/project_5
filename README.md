# Analýza cestovního ruchu v ČR (2023–2024)

## Popis projektu
Tento projekt vznikl jako projekt práce v nástroji **Power BI**. Za cíl jsem si zvolil analyzovat data Českého statistického úřadu (ČSÚ) 
týkající se cestovního ruchu, konkrétně nákladů na cesty, počtu přenocování a profilu účastníků.

## Klíčové vlastnosti
* **Interaktivní report:** 3 strany analýzy (Přehled, Struktura cet, Profil účastníka).
* **Datový model:** Propojení faktové tabulky s číselníky (hvězdicové schéma).
* **DAX metriky:** Vlastní výpočty pro celkové náklady a dynamické filtrování.

## Použitá data
* `CRU06AGEN.csv` - Hlavní data o cestovním ruchu (Zdroj: ČSÚ).
* `krok_okruhy.csv` - Číselník statistických okruhů.

## Jak si report prohlédnout?
1. Stáhněte si soubor `.pbix` z tohoto repozitáře.
2. Otevřete jej v aplikaci **Power BI Desktop**.
